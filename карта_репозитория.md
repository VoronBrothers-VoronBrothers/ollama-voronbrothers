# Карта репозитория ollama fork

## 1. High-Level Overview

- **Название:** `ollama fork` (монорепо, модуль Go `github.com/ollama/ollama`, Go 1.26).
- **Стек:** Go (CLI/TUI/API), C/C++ + CUDA/ROCm (llama.cpp через FetchContent в CMake), MLX для Apple Silicon (`x/mlxrunner`), SQLite (хранилище моделей), Gin (HTTP API), Cobra (CLI), Bubble Tea (TUI).
- **Назначение:** локальная платформа загрузки, конвертации и инференса LLM с CLI/TUI и HTTP-API (нативный `/api/*` + совместимость OpenAI/Anthropic).
- **Точка входа:** `main.go` → `cmd.NewCLI().ExecuteContext(...)` (Cobra root в `cmd/cmd.go`, `Use: "ollama"`).

## 2. Атомарная карта директорий и файлов

### Корень
- `main.go` — точка входа бинарника, делегирует в Cobra CLI.
- `go.mod` / `go.sum` — зависимости Go (gin, cobra, bubbletea, sqlite3, tree-sitter и др.).
- `CMakeLists.txt` + `CMakePresets.json` — корневой CMake-оркестратор для C/CUDA/MLX подпроектов; правила бэкендов лежат в `cmake/`.
- `Dockerfile`, `.dockerignore` — сборка Docker-образа.
- `.golangci.yaml` — конфиг линтера Go.
- `LLAMA_CPP_VERSION`, `MLX_VERSION`, `MLX_C_VERSION` — закреплённые версии внешних C/C++-зависимостей.
- `PLAN-xlow.md`, `AGENTS.md`, `CLAUDE.md` — служебные заметки/инструкции для ИИ-агентов [Требует уточнения кода].

### CLI / TUI
- `cmd/` — все команды CLI (root: create, run, stop, serve, pull, push, signin/login, list, ps, cp, rm, runner, gpu-discover):
  - `cmd/cmd.go` — дерево Cobra и обработчики команд.
  - `cmd/tui/` — интерактивный TUI на Bubble Tea (чат-селектор моделей, confirm, signin).
  - `cmd/interactive.go` — режим «говорилки» (`ollama run MODEL`).
  - `cmd/launch/` — интеграции запуска внешних агентов/IDE: claude, codex, cline, copilot, droid, kimi, muse, openclaw, qwen, vscode и т.д. (по одному файлу на провайдера).
  - `cmd/bench/`, `cmd/keytest/` — бенчмарк и тест ввода.
- `progress/` — спиннеры и прогресс-бары CLI/TUI (`bar.go`, `stepbar.go`).
- `readline/` — ввод строки в терминале.

### Сервер и API
- `server/` — HTTP-сервер (Gin):
  - `routes.go` — маршруты: `/api/chat|generate|embed(dings)|pull|push|create|show|tags|list(=ps)|delete|copy|status|version|me`, OpenAI-совместимые `/v1/chat/completions, /v1/completions, /v1/models, /v1/embeddings, /v1/responses(/compact), /v1/messages (Anthropic)`, `/v1/audio/transcriptions`, экспериментальные web_fetch/web_search/model-recommendations.
  - `sched.go` — планировщик загрузки моделей на устройства.
  - `download.go`, `upload.go`, `create.go`, `images.go`, `model_list.go`, `prompt.go`, `quantization.go` — операции с моделями и GGUF-метаданными (`gguf_metadata.go`).
  - `cloud_proxy.go`, `codex_proxy.go`, `auth.go` — прокси облака/аутентификация.
- `api/` — Go HTTP-клиент API для внешних программ: `client.go`, `types.go`.
- `middleware/` — middleware Gin: OpenAI (`openai.go`), Anthropic (`anthropic.go`), метрики (`metrics.go`), web-search.
- `openai/`, `anthropic/` — адаптеры протоколов (OpenAI responses, Anthropic messages + трассировка).
- `harmony/` — парсер стриминга Harmony.

### Инференс / бэкенды
- `ml/` — интерфейс бэкенда: `backend.go` (`Backend`, `Tensor`, контексты), `device.go` (устройства GPU/CPU/NPU).
- `ml/backend/ggml/` — вэндордированный исходник GGML (C++ + CUDA, напр. `template-instances/*.cu`) для CMake-сборки.
- `llama/` — сборка llama.cpp: `llama/server/CMakeLists.txt` (FetchContent закреплённой версии, git-pатчи), привязки MLX (`mlx/`, `vendor-mlx-c-headers.cmake`).
- `llm/` — управление процессом C++-сервера инференса: `llama_server.go`, `llama_binary.go`, платформенные `llm_darwin/windows`.
- `runner/` — команда `ollama runner`: тонкий обёртка над MLX-инжинеру (`x/mlxrunner`).
- `cmake/` — CMake-подпроекты бэкендов.

### Модели, токенизация, шаблоны
- `model/parsers/` — парсеры конфигурации конкретных семейств моделей (gemma3/4, qwen3/35/38, glm46/47, deepseek3, olmo3, ministral, nemotron3nano и т.д.) — по файлу на семью.
- `model/renderers/` — рендереры промптов (форматирование диалога) [частично].
- `tokenizer/` — токенизаторы: BPE (`bytepairencoding.go`), SentencePiece, WordPiece.
- `template/` — промпт-шаблоны `.gotmpl` + JSON на каждый класс моделей (alfred, alpaca, chatml, codellama и т.д.).
- `types/model/` — Go-структуры сущностей: capability, config generation, name.

### Конвертация и форматы
- `convert/` — конвертеры весов → GGUF по семействам (gemma2/3, deepseek2, embedding-gemma, command-r, bert и др.); точка входа `convert.go`.
- `fs/` — файловые утилиты: `ggml`, `gguf`, пути и конфиг (`config.go`).
- `manifest/` — манифест слоёв модели (layers), пути.
- `format/` — форматирование байтов/времени для вывода CLI.

### Хранилище и конфигурация
- `app/store/` — SQLite-хранилище: `store.go`, `database.go`, `schema.sql`, image/cloud config.
- `app/server/`, `app/darwin/`, `app/cmd/`, `assets/` — упаковка десктопного приложения (macOS).
- `envconfig/` — переменные окружения и конфигурация (включая отключение облака — `internal/cloud/policy.go`).
- `auth/` — хранение токенов авторизации.

### Прочее
- `parser/` — парсер Modelfile (в т.ч. расширение путей `FROM`) для `ollama create`.
- `thinking/` — разбор thinking/reasoning токенов и шаблоны (`parser.go`, `template.go`).
- `tools/` — шаблоны вызова tools/function-calling (`tools.go`, `template.go`).
- `integration/` — интеграционный тест-набор API (audio, chat, embed, generate, concurrency) — только тесты.
- `logutil/` — утилиты логирования. `version/` — константа версии.
- `mlx/compat` — совместимость MLX-привязок.
- `discover/` — обнаружение GPU/CPU: CUDA, AMD, Darwin (`gpu.go`, `cuda_compat.go`, `llama_server.go`).
- `internal/` — внутренние модули: cloud policy, modelref, proxy, orderedmap.
- `x/` — экспериментальные компоненты: `mlxrunner` (MLX), imagegen, quant safetensors, tokenizer, transfer.
- `agent/` — агентские сессии/skills: approval, compactor, events, registry, skill activation [Требует уточнения кода].
- `docs/` — документация (mdx) + **OpenAPI-спецификация** `docs/openapi.yaml`, `api.md`.
- `scripts/` — сборки и инсталляция: `build_linux.sh`, `build_darwin.sh`, `build_windows.ps1`, `build_docker.sh`, `install.sh/.ps1`, `push_docker.sh`, `deduplicate_cuda_libs.sh`, `env.sh`.

## 3. Архитектурный граф и потоки данных

**Поток CLI → сервер:**
`main.go` → **`cmd/cmd.go`** (Cobra) → команды `run/pull/serve/create/…`; при `ollama run` — интерактив (`cmd/interactive.go`) + TUI (`cmd/tui`). Все CLI-операции обращаются к локальному HTTP-API через пакет **`api/client.go`**.

**Поток запроса инференса:**
HTTP (Gin, **`server/routes.go`**) → **`sched.go`** (выбор устройства/модели) → запуск бэкенда: `llm/llama_server.go` (C++ llama.cpp-процесс, собран через `cmake/` + `ml/backend/ggml`) или MLX (`x/mlxrunner`). Промпт собирается из **`model/parsers`** (config модели) + **`template/*.gotmpl`** + **`tokenizer`**. Ответ стримится обратно по HTTP.

**Поток загрузки/конвертации:**
`server/download.go` → `manifest/` (layers GGUF) → хранилище **`app/store`** (SQLite). Конвертация: `convert/*.go` читает исходные веса и пишет GGUF; метаданные — `fs/gguf`.

**Совместимость:** пакеты **`openai/`, `anthropic/`, `middleware`** переформатируют нативный API в OpenAI/Anthropic протоколы на роутах `/v1/*`.

**Зависимости (верх → низ):**
- `server` зависит от: `sched` → `ml`/`llm`/`runner`; `model/parsers`, `template`, `tokenizer`; `app/store`; `internal/cloud`.
- `cmd` зависит от: `api`, `progress`, `readline`, `tui`, `launch/*`.
- C/CUDA-слой (`cmake`, `llama`, `ml/backend/ggml`) не знает про Go; связка — через cgo/субпроцесс в **`llm/`**.

## 4. Ключевые конфигурации и скрипты

| Файл | Назначение |
|---|---|
| `main.go` + `cmd/cmd.go` | Сборка CLI: `go build .` → бинарник `ollama` |
| `CMakeLists.txt`, `cmake/`, `llama/server/CMakeLists.txt` | C-сборка GGML/llama.cpp (FetchContent, версии из `LLAMA_CPP_VERSION`) |
| `Dockerfile` + `scripts/build_docker.sh`, `push_docker.sh` | Docker-образ и публикация |
| `scripts/build_{linux,darwin,windows}` | Нативные сборки с бэкендами |
| `scripts/install.{sh,ps1}` | Установка на Linux/Windows |
| `.golangci.yaml` | Линтинг Go |
| `envconfig/`, `internal/cloud/policy.go` | Переменные окружения (в т.ч. отключение облака) |

**Основные команды:**
- `go build .` — бинарник CLI+сервер; `go test ./...` — тесты (много `*_test.go` по пакетам).
- `cmake --preset ... && cmake --build` — C/CUDA/MLX компоненты.
- `ollama serve`, `ollama run MODEL`, `ollama pull/push/create/list/rm`.

## 5. Шпаргалка для модификаций (Extension Guide)

1. **Новый HTTP-эндпоинт** → `server/routes.go` (роут) + обработчик в пакете `server/`; типы ответов — `api/types.go`; спеку обновить в `docs/openapi.yaml`.
2. **Новая модель (семейство)** → парсер конфига: `model/parsers/<family>.go`; шаблон промпта: `template/*.gotmpl` + `.json`; конвертер весов: `convert/convert_<family>.go`.
3. **Новый CLI-командный флаг** → дерево Cobra в `cmd/cmd.go`; TUI-элементы — `cmd/tui/`.
4. **Свой провайдер интеграции (launch)** → новый файл `cmd/launch/<provider>.go` по образцу существующих.
5. **Новый бэкенд инференса** → реализация интерфейса `ml/backend.go` + CMake-подпроект в `cmake/`; регистрация выбора — `ml/device.go`.
6. **Смена поведения облака** → `envconfig/`, `internal/cloud/policy.go`, `server/cloud_proxy.go`.
