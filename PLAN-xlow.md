# План: уровень "xlow" (минимальный thinking) без патча llama.cpp

Цель: создать модель-копию с прикрученным xlow-уровнем размышления.

## Этап 0 — Разведка (15 мин)
- [ ] Найти установленную thinking-модель и её GGUF:
      `ls ~/.ollama/models/blobs/` + сопоставление по `ollama show <модель> --modelfile`
- [ ] Выгрузить шаблон:
      `gguf-dump <blob.gguf> | grep -A2 chat_template` (или через python gguf)
- [ ] Найти в шаблоне блок маппинга effort → think budget
      (ищет строки: reasoning_effort, think, budget, set think)

## Этап 1 — Патч шаблона (30–60 мин)

- [ ] Дописать уровень xlow:
      - вариант A: новый уровень `"xlow" → <N> токенов` (N = половина от low или 32–64)
      - вариант B: просто ужать число под "low" до минимума
- [ ] Проверить синтаксис Jinja (кавычки, закрывающие `{% endset %}`)

## Этап 2 — Запись в GGUF (10 мин)

## Этап 5 — Замер и отладка (20 мин)

## Риски
- Шаблон однострочный и длинный → править только через diff, не вживую
- Ollama кэширует по hash → новый GGUF = новое имя обязательно
- Если шаблон модели простой (Qwen3) — всё быстрее; если сложный — закладыва́ть время на чтение логики
