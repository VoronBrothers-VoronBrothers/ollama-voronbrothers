# Сборка и версия бинарника

## 1. Как компилируется бинарник

```bash
cd "/home/voron/Документы/VB-ollama/GitHub Ollama кастомный бинарник/ollama 0.34.1 13-09-2026 voron"

go build \
  -ldflags "-X github.com/ollama/ollama/version.Version=0.34.1-voron-ts" \
  -o /tmp/ollama-patched .

sudo mv /tmp/ollama-patched /usr/local/bin/ollama
```

### Важные моменты:
- **`mv`, а не `cp`** — на занятом бинарнике `cp` даёт «Текстовый файл занят».
  `mv` атомарно меняет inode; текущие процессы (сервер, TUI) продолжают работать со старым inode без перезапуска.
- **CGO** нужен: `go-sqlite3`, `x/mlxrunner` (mlx-c из хедеров репо).
  `CGO_ENABLED=0` упадёт на `x/mlxrunner`. Go: apt `golang-go` (1.26).
- Сервер (`ollama serve`) и TUI перезапускать **не обязательно** после замены;
  следующий старт подхватит новый бинарник автоматически.

## 2. Где изменять номер версии

### Вариант A — через ldflags при сборке (рекомендуется)
Версия задаётся в команде сборки:
```bash
-ldflags "-X github.com/ollama/ollama/version.Version=0.34.1-voron-ts"
```
Подставить нужную версию вместо `0.34.1-voron-ts`.

### Вариант B — в исходнике (по умолчанию)
Файл: **`version/version.go`**

```go
package version

var Version string = "0.0.0"   // ← сюда
```

По умолчанию стоит `"0.0.0"`; без `-ldflags` клиент ругается «client version is 0.0.0».
